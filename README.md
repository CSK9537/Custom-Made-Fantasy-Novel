# 📖 국가 연금술사 연구 일지 (Interactive Visual Novel & Photobook)

## 1. 서비스 소개

- **어떤 서비스인지 한 문장 설명**: 유저가 직접 '강철의 연금술사' 세계관의 연금술사가 되어 AI 마스터(Gemini)와 TRPG를 진행하고, 그 모험의 기록과 생성된 이미지(DALL-E 3)를 실제 포토북으로 출판하는 인터랙티브 웹 애플리케이션입니다.
- **누구를 위한 서비스인지 (타겟 고객)**: 서브컬처(애니메이션, TRPG) 팬덤 및 나만의 맞춤형 스토리북을 소장하고 싶은 유저.
- **주요 기능 목록**:
  - **AI 게임 마스터**: Gemini 2.5 Flash를 활용한 실시간 스토리텔링 및 선택지 제공.
  - **실시간 씬 연성**: DALL-E 3를 통한 스토리 맞춤형 고품질 애니메이션 스크린샷 렌더링.
  - **자동 출판 시스템**: Sweetbook API를 연동하여 생성된 텍스트와 이미지를 24~130p 규격의 포토북으로 자동 조립 및 인쇄 주문.

## 2. 실행 방법

    # 설치
    cd backend && npm install
    cd ../frontend && npm install

    # 환경변수 설정
    cd ..
    cp .env.example .env
    # .env 파일에 각 API Key(Sweetbook, Gemini, OpenAI) 및 이메일 정보를 입력

    # 실행 (각각 새로운 터미널 창을 열어 실행해야 합니다)
    # [터미널 1] 백엔드 실행
    cd backend
    node index.js

    # [터미널 2] 프론트엔드 실행
    cd frontend
    npm run dev

## 3. 사용한 API 목록

| API                              | 용도                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| `POST /books`                    | 새로운 연구 일지(SQUAREBOOK_HC) 뼈대 생성                                                  |
| `POST /covers`                   | 스토리를 바탕으로 생성된 표지 이미지 삽입                                                  |
| `POST /contents`                 | 각 턴마다 생성된 씬 이미지를 규격(최소 24p~최대 130p)에 맞게 내지로 삽입 및 빈 페이지 보정 |
| `POST /books/{bookUid}/finalize` | 내지 조립 완료 후 책 상태 최종화                                                           |
| `GET /credits/balance`           | 사령부 지원금(충전금) 잔액 조회                                                            |
| `POST /credits/sandbox-charge`   | 테스트 결제를 위한 지원금 자동 충전                                                        |
| `POST /orders/estimate`          | 출판 견적 조회 및 잔액 검증                                                                |
| `POST /orders`                   | 멱등성 키를 활용한 최종 인쇄 및 배송 주문 접수                                             |
| `GET /orders/{orderUid}`         | 취소 가능 여부 검증을 위한 주문 상태 조회                                                  |
| `POST /orders/{orderUid}/cancel` | 유저 변심 시 주문 취소 및 환불 처리 (비상탈출)                                             |
| `Webhook (Inbound)`              | 결제 완료, 배송 출발 등 상태 변경 이벤트 수신 및 서명 검증                                 |

## 4. AI 도구 사용 내역

| AI 도구                    | 활용 내용                                                                                                             |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Gemini 2.5 Flash (API)** | TRPG 스토리 진행, 선택지 제공, DALL-E 3용 영문 프롬프트 생성 (안전 필터 우회 및 앵커링 기법 적용)                     |
| **DALL-E 3 (API)**         | 매 턴 상황에 맞는 일관된 애니메이션 화풍의 씬 이미지 및 표지 생성                                                     |
| **Gemini 3.1 Pro (Chat)**  | Sweetbook API 문서 분석, 아키텍처 설계, 비동기 통신 로직 및 웹훅 보안 서명 알고리즘 구현, UI/UX 다크 테마 디자인 작성 |

## 5. 설계 의도

- **왜 이 서비스를 선택했는지**: 디지털로만 소비되고 휘발되는 AI 챗봇의 한계를 넘어, 유저가 직접 참여한 서사를 '실물 포토북'이라는 만져지는 결과물로 남김으로써 Sweetbook API의 가치를 극대화하고자 했습니다.
- **이 서비스의 비즈니스 가능성을 어떻게 보는지**: 특정 IP와 결합한 '굿즈 제작 플랫폼'으로 확장이 가능합니다. 유저의 몰입도가 높고 최종 산출물에 대한 애착이 강해, 기존 포토북 시장을 넘어 서브컬처 팬덤을 타겟으로 한 고단가 프리미엄 맞춤형 출판 비즈니스로 발전할 수 있습니다.
- **더 시간이 있었다면 추가했을 기능**:
  1. 유저의 대화 내역 전체를 텍스트 레이어로 내지에 함께 인쇄하는 커스텀 템플릿 기능.
  2. Webhook과 연동하여 책이 배송 중일 때 게임 내 이벤트(예: 사령부의 추가 지령)가 발생하는 O2O(Online to Offline) 상호작용 기능.
